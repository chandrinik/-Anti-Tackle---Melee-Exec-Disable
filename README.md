In order to make the script to work, make a folder with the name of your choice
Then take this folder and place it inside the [standalone] folder (inside your resources folder)
Make sure to use "ensure_yourfoldername in the server.cfg file in order to get the script enabled automaticly.
You can edit the message which appears in chat when the button is pressed by editing the line 55 and 61.
You can edit the distance which the script will use in order to disable the actions in line 86 (Use only numbers like 5.0)
You can edit the message which appears when the player comes near to another player in line 115
You can edit the button which will be used in line 66.
